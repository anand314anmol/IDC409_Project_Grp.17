# IDC409_Project_Grp.17
Project repo for the IDC409 Data Science course (Group 17)

## Description of Files
- _student-mat.csv_ --- cleaned dataset of math class

- _student-por.csv_ --- cleaned dataset of portugese class
- EDA.ipynp --- General analysis of the dataset
- _Linear_Regression_Math_Class.ipynb_ --- linear regression model trained on math class dataset (by Anmol)
- _Linear_Regression_Portugese_Class.ipynb_ --- linear regression model trained on portugese class dataset (by Anmol)
- _SVM_Math_Class.ipynb_ --- SVM Model trained on Math class dataset (by Anmol)
- _SVM_Portugese_Class.ipynb_ --- SVM Model trained on Portugese class dataset (by Anmol)
- _Decision_tree_regre_Math_Class.ipynb_ --- SVM Model trained on Math class dataset
